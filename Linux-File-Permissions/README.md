# Linux File Permissions – Screenshots

## Overview

This folder contains screenshots of the Linux commands used during the file permissions management activity.

The screenshots demonstrate the practical steps I performed while working with Linux file and directory permissions.

## Commands Demonstrated

- `ls -l` – View file and directory permissions.
- `ls -la` – Display all files, including hidden files.
- `chmod` – Modify file and directory permissions.

## Purpose

These screenshots provide practical evidence of my Linux command-line experience and demonstrate how I examined and managed file permissions using the principle of least privilege.
