# Home Network Asset Inventory

## Project Overview

In this project, I created an inventory of network devices connected to a home network. The purpose was to identify important devices, document their owners, locations, network access, and determine their sensitivity levels.

I reviewed different types of devices and considered the information they store and their importance to the home network.

## 1. Network Asset Inventory

| Asset | Network Access | Owner | Location | Sensitivity |
|---|---|---|---|---|
| Network Router | Continuous | Homeowner | On-premises | Confidential |
| Desktop | Occasional | Homeowner | On and Off-premises | Restricted |
| Guest Smartphone | Occasional | Friend | On-premises | Internal-only |
| Game Console | Occasional | Homeowner | On-premises | Internal-only |
| Server | Continuous | Homeowner or Company | On and Off-premises | Restricted |
| Internet Service Provider (ISP) | Occasional | ISP | Off-premises | Public |
| TV | Occasional | Homeowner | On-premises | Internal-only |

## 2. Asset Details and Security Considerations

### Network Router
- Provides network connectivity.
- Has both 2.4 GHz and 5 GHz connections.
- All devices on the home network connect to the 5 GHz frequency.

### Desktop
- Contains private information, such as photos.
- Requires protection against unauthorized access.

### Guest Smartphone
- Belongs to a friend.
- Connects to the home network.
- Requires consideration when allowing guest access.

### Game Console
- Used for entertainment and other activities.
- Connects to the home network occasionally.

### Server
- Can store confidential information, including Personally Identifiable Information (PII).
- Requires protection because of the sensitive information it stores.

### Internet Service Provider (ISP)
- Provides internet connectivity to the home network.
- Account credentials are used.
- The identified risk level is low.

### TV
- Used for news and entertainment purposes.
- Connects to the home network occasionally.

## 3. Sensitivity Categories

The following sensitivity categories and access designations were considered during the inventory assessment.

| Sensitivity | Access Designation |
|---|---|
| Restricted | Need-to-know |
| Confidential | Limited to specific users |
| Internal-only | Users on-premises |
| Public | Anyone |

## Project Summary

Through this activity, I learned how to identify and document network assets connected to a home network.

I reviewed device ownership, network access, location, and the type of information stored on each device. I also learned how to classify assets according to their sensitivity and access requirements.

This activity helped me understand the importance of maintaining a network inventory and identifying devices that require additional protection.

- Network asset identification
- Network inventory management
- Device classification
- Data sensitivity assessment
- Access control awareness
- Identification of sensitive information
- Basic network security risk assessment
