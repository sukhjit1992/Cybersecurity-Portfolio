# Botium Toys: Security Controls and Compliance Audit

## Project Overview

This project is a cybersecurity audit assessment of Botium Toys, a fictional retail company. The purpose of this assessment was to evaluate existing security controls, identify security risks, review compliance practices, and recommend improvements to strengthen the organization's overall security posture.

## 1. Scope and Goals

The audit covered the organization's security program, including:

- Employee devices and equipment
- Internal network and systems
- Business applications and databases
- Data storage and retention
- E-commerce and inventory management
- Physical security of offices, storefront, and warehouse
- Legacy systems and maintenance practices

**Goal:** Identify security gaps, assess existing controls, and recommend improvements to protect company assets and sensitive customer information.

## 2. Risk Assessment

The assessment identified several security weaknesses that could expose the organization to data breaches, operational disruptions, and compliance risks.

**Overall Risk Score: 8/10 (High)**

Key risks identified:

- All employees had access to internally stored data, including sensitive customer information.
- Customer credit card information was not encrypted.
- Least privilege and separation of duties were not implemented.
- No Intrusion Detection System (IDS) was installed.
- No disaster recovery plan or critical data backups were available.
- Password requirements were weak, with no centralized password management system.
- Legacy systems lacked a regular maintenance schedule.

## 3. Security Controls Assessment

I evaluated the organization's existing security controls and identified areas requiring improvement.

Controls reviewed:

- Least Privilege
- Disaster Recovery Plans
- Password Policies
- Separation of Duties
- Firewall
- Intrusion Detection System (IDS)
- Data Backups
- Antivirus Software
- Legacy System Monitoring and Maintenance
- Data Encryption
- Password Management System
- Physical Security (Locks, CCTV, and Fire Detection)

## 4. Compliance Assessment

I reviewed the organization's security practices against the following standards and frameworks:

### PCI DSS - Payment Card Industry Data Security Standard

Evaluated requirements related to:

- Restricted access to customer payment information
- Secure storage and processing of credit card data
- Data encryption
- Secure password management

### GDPR - General Data Protection Regulation

Evaluated requirements related to:

- Protection of EU customers' personal information
- Data privacy and security
- Breach notification within 72 hours
- Data classification and inventory
- Privacy policies and documentation

### SOC 1 and SOC 2

Reviewed practices related to:

- User access policies
- Confidentiality of sensitive information (PII/SPII)
- Data integrity
- Data availability

## 5. Recommendations

Based on the assessment, I recommended the following improvements:

1. Implement least privilege and role-based access controls.
2. Introduce separation of duties.
3. Encrypt sensitive customer and payment information.
4. Deploy an Intrusion Detection System (IDS).
5. Establish disaster recovery plans and regular data backups.
6. Strengthen password policies and implement centralized password management.
7. Establish scheduled maintenance for legacy systems.
8. Improve data classification and asset inventory management.
9. Review privacy policies and compliance requirements with stakeholders.
10. Evaluate the need for a Data Protection Officer (DPO), based on GDPR applicability.
